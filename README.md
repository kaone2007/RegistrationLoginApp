# RegistrationLoginApp

## Programming 1A - Registration and Login Application

This Java application was developed as part of a Programming 1A project. The application allows a user to register and log in while validating the information entered.

## Features

- User registration
- Username validation
- Password complexity validation
- South African cell phone number validation
- User login
- Login status messages
- JUnit testing

## Technologies Used

- Java
- Apache NetBeans
- Maven
- JUnit 5
- Git
- GitHub

## Project Structure

- `Login.java` - Contains the registration and login validation methods.
- `Main.java` - Runs the application and handles user input.
- `LoginTest.java` - Contains JUnit tests for the application.
- `pom.xml` - Contains the Maven project configuration and dependencies.

## Testing

JUnit tests were created to test the functionality of the application, including username, password, cell phone number and login validation.

The project successfully passed all 13 JUnit tests.
